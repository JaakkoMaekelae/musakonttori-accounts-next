# Musakonttori-sanasto

## Yleiset

| Termi | Selitys |
|-------|---------|
| **Org / Organization** | Organisaatio. Artist, venue, festival, label, yms. Yksi todellinen toimija. |
| **Entitlement** | Oikeus käyttää tiettyä featurea. Tulee planista, add-onista, trialista tai manuaalisesta grantista. |
| **Impersonation** | Admin-toiminto: kirjaudu sisään toisena käyttäjänä. Kaikki lokitetaan. |
| **Customer 360** | Yhdistetty näkymä asiakkaasta: seuraukset, ostot, liput, merch — kaikista tuotteista. |
| **Shared Platform** | Yhteiset palvelut kaikille tuotteille: identity, orgs, billing, analytics. |
| **Clerk** | Autentikointipalvelu. Yksi Clerk-instanssi kaikille tuotteille. |

## Stageflow

| Termi | Selitys |
|-------|---------|
| **Fan CRM** | Artistin fanitietokanta. Seuraajat, ostohistoria, segmentointi. |
| **Booking** | Keikkavaraus: artist ↔ venue/festival. |
| **Trip Planner** | Kiertuesuunnittelu. Reititys, logistiikka. |
| **Demand Intelligence** | Data-driven ennuste: missä artistilla on kysyntää. |

## Ticketing

| Termi | Selitys |
|-------|---------|
| **Ticket type** | Lipputyyppi: General Admission, VIP, Early Bird. |
| **QR ticket** | QR-koodillinen lippu. Luetaan scannerilla ovella. |
| **Scanner** | Mobiilisovellus lipunlukemiseen ovella. Offline-tuki. |
| **Guest list** | Vieraslista. Ilmaiset sisäänpääsyt. |
| **Resale** | Jälleenmyynti. Fan myy lipun toiselle fanille. |

## SmartLink

| Termi | Selitys |
|-------|---------|
| **Bio link** | Artistin linkkipuu. Kaikki tärkeät linkit yhdessä osoitteessa. |
| **Fan capture** | Fanin yhteystietojen kerääminen. Sähköposti, puhelin, some. |
| **Campaign** | Markkinointikampanja. A/B-testaus, kohdennus. |
| **Link builder** | Drag-and-drop linkkisivun rakentaja. |

## LiveGuide

| Termi | Selitys |
|-------|---------|
| **Map** | Interaktiivinen festarikartta. POI:t, reitit. |
| **Schedule** | Aikataulu. Favoriitit, muistutukset. |
| **Alert** | Push-notifikaatio. Aikataulumuutokset, hätätiedotteet. |
| **Check-in** | Sisäänkirjautuminen tapahtumaan. Ticket walletista. |

## Market

| Termi | Selitys |
|-------|---------|
| **Store** | Artistin oma kauppa. Tuotteet, brändäys. |
| **Merch** | Fyysiset tuotteet: paidat, vinyylit, julisteet. |
| **Digital product** | Digitaalinen tuote: äänitiedosto, PDF, exclusive content. |
| **App marketplace** | Kolmannen osapuolen sovellukset. Revenue share. |

## SoundLaunch

| Termi | Selitys |
|-------|---------|
| **Agreement** | Sopimus. Artisti ↔ label, tuottaja ↔ artisti. |
| **Royalty** | Rojalti. Maksettava korvaus oikeudenhaltijalle. |
| **Split** | Tulonjako. Prosenttiosuudet eri osapuolille. |
| **Payout** | Maksu. Rojaltien tilittäminen oikeudenhaltijoille. |

## Tekniset

| Termi | Selitys |
|-------|---------|
| **ADR** | Architecture Decision Record. Dokumentoitu arkkitehtuuripäätös. |
| **Prisma** | TypeScript ORM PostgreSQL:lle. Kaikki DB-kyselyt Prisman kautta. |
| **Zod** | TypeScript-skeemakirjasto. API-validointi, env-muuttujat. |
| **next-intl** | Kansainvälistämiskirjasto Next.js:lle. Suomi oletuksena. |
| **Husky** | Git hooks -työkalu. Estää pushin jos build/typecheck epäonnistuu. |
| **CSP** | Content Security Policy. Turvallisuusheaderi. |
| **RLS** | Row Level Security. Tietokantatason käyttöoikeusrajoitus. |
